# Triton Exercises

This repository contains practical Triton exercises focused on high-performance GPU kernel development. The work covers core and advanced CUDA/Triton patterns, including:

- matrix multiplication and block matrix multiplication
- grouped matrix multiplication
- softmax kernels
- flash attention
- tensor layouts and memory-efficient data movement
- warp specialization
- CTA and multi-CTA kernels
- TMA (Tensor Memory Accelerator) usage
- persistent kernels

The goal is to build a deeper understanding of how modern GPU kernels are structured and optimized in Triton, with emphasis on performance, parallelism, and memory behavior.
